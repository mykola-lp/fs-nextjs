# Welcome to Blog App

This is a **modern blogging platform** built with Next.js, featuring user authentication, blog post management, and a clean, intuitive interface.

**Course:** [Full Stack Open Next.js](https://courses.mooc.fi/org/uh-cs/courses/full-stack-open-nextjs)

## Features

- **Create and Manage Notes/Blogs** - Write and publish your thoughts
- **User Profiles** - Personalized user pages
- **Authentication** - Secure login and registration
- **Comments** - Engage with blog posts

## Getting Started

To start exploring:

1. [Register](/register) for a new account
2. [Login](/login) to access your dashboard
3. [Create a new note post](/notes/new)
4. [Create a new blog post](/blogs/new)
5. View [all notes](/notes) and [notes](/notes)
6. View [all blogs](/blogs) and [blogs](/blogs)
7. View [all users](/users) and [users](/users)
